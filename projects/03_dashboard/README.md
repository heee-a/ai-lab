# 交互式仪表盘：自包含 HTML，双击即开

一个不依赖任何后端的可视化项目：用 plotly 生成**单文件** `dashboard.html`
（4.7MB，plotly.js 已内联，离线双击可打开），包含两个高级视图：

## ① 世界发展动画（Gapminder 风格）

2000-2023 年 200+ 国家的动画散点图：

- X 轴：人均GDP（对数轴），Y 轴：预期寿命
- 气泡大小 = 人均CO2，颜色 = 世界银行地区分组
- 点击播放看 24 年演变：全体国家向右上角迁移（变富、变长寿），
  中国的气泡从左下方一路跑到中上部

## ② 中国 18 城气候热力图

城市 × 月份的均温矩阵（2019-2024 均值），按年均温排序。
一眼看出：三亚全年深色、哈尔滨冬季深蓝、全国夏季同热——
这是数据项目里文字结论的可视化版本。

## 为什么是"自包含单文件"

面试演示最怕现场环境问题。`include_plotlyjs=True` 把 plotly.js 内联进
HTML，发给谁都能双击打开；`4.7MB` 换来零依赖的展示可靠性，值得。

## 复现

```bash
python build_dashboard.py
# 产出 dashboard.html；数据来自 data-portfolio 的真实采集
```
