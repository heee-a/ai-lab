# 机器学习端到端：从社会发展特征推断国家收入等级

一个刻意做「小而完整」的监督学习项目：任务真实（世界银行数据）、
流程标准（特征→基线→交叉验证→可解释性）、并且包含一个**标签泄漏对照实验**——
这是多数演示项目会踩坑、面试官最爱追问的话题。

## 任务定义

> 不看任何收入指标，仅凭社会发展特征（预期寿命、人均CO2、城市化率），
> 预测一个国家属于世界银行的哪个收入等级（4 分类，192 国）。

## 最重要的设计：防泄漏

收入等级本身就是世界银行**按人均收入阈值划定**的。把人均GDP放进特征，
等于把答案喂给模型。本项目做了对照实验：

| 特征集 | 5 折交叉验证准确率 |
|---|---|
| 防泄漏（寿命/CO2/城市化） | **66.1%**（RF 68.3%） |
| 泄漏对照（+人均GDP） | 76.6% |

泄漏对照的 10 个百分点提升是**虚高**：模型一旦上线就要"输入GDP"才能工作，
而业务价值恰恰是"不查GDP也能推断"。图见 [charts/leakage.png](charts/leakage.png)。

## 实验结果（防泄漏特征）

- 逻辑回归：acc 66.1% ± 11.4%；随机森林：**acc 68.3% ± 5.0%，macro-F1 0.700**
- 训练集内准确率 96.9% vs 交叉验证 68.3%——方差主导的过拟合差距，说明
  192 个样本下必须以交叉验证为准（这个对比本身就是教学点）；
- 置换重要性：预期寿命 ≫ 城市化率 > 人均CO2（见 [charts/importance.png](charts/importance.png)）；
- 混淆矩阵：高收入/低收入两端几乎不混淆，混淆集中在相邻等级
  （见 [charts/confusion_matrix.png](charts/confusion_matrix.png)）——有序类别
  的相邻误判是可接受的业务误差。

## 使用

```bash
python data_prep.py                     # 构建数据集（2023 年快照，192 国）
python train.py                         # 实验 + 图表 + models/model.joblib
python predict.py --life-exp 74.2 --co2-pc 6.7 --urban 64    # 预测并输出概率分布
python predict.py --country CHN         # 用数据集中的国家演示
```

预测输出示例（概率分布条形图文字版）：

```

```

## 局限（README 不回避）

- 192 个样本、3 个特征，容量有限——价值在方法论演示而非生产精度；
- 训练集内评估仅用于可解释性分析，模型选择一律以交叉验证为准；
- 收入等级与年份相关（阈值逐年抬高），当前用的是 2023 名义口径。
