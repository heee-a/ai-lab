# 深度学习对照实验：PyTorch MLP 分类手写数字

一个刻意"唱反调"的深度学习项目：在 1797 个样本的 digits 数据集上训练
PyTorch 多层感知机，与经典方法正面对比——**结果是深度模型输了近 4 个
百分点，而这个负结果正是项目的价值**。

## 实验设置

- 数据：sklearn digits，1797 × 64（8×8 像素），10 类，25% 分层留出集；
- 模型：MLP 64→128→64→10，ReLU + Dropout(0.2)，Adam(1e-3)，80 epochs；
- 防泄漏口径：标准化用训练集统计量；固定随机种子完全可复现；
- 对照基线：ml-bench/01 同口径实测 SVM-RBF 交叉验证 **98.25%**、
  留出集 **98.0%**。

## 结果

| 模型 | 留出集准确率 |
|---|---|
| SVM-RBF（经典，对照） | **98.0%** |
| PyTorch MLP（本项目） | 94.4% |

**为什么深度模型输了？** 1797 个样本喂不饱带 Dropout 的三层网络；
经典方法（SVM 的间隔最大化）在小样本高维数据上有天然优势。
宏平均 F1 0.944，混淆集中在 1/8 两类（少数易混字形）。

**如果要缩小差距（未做，如实列为方向）**：数据增广（平移/旋转）、
卷积结构利用像素空间局部性、预训练表示。每条都需要更多数据或算力，
在"1797 样本 + 纯 MLP"的设定下，94.4% 就是诚实的结果。
